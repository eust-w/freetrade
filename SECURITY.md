# Security

Do not post credentials or private logs in issues. Use GitHub private vulnerability reporting when available, or contact the maintainer through the public profile to arrange a private report.

This project has no brokerage connection or automated order execution. Deploy with a limited SSH account, preverified host keys, explicit destinations, and a private environment configuration. Treat upstream strings and imported snapshots as untrusted.

The repository was assembled from an explicit file allowlist. Browser sessions, private deployment details, raw operational logs, and real market-data exports are excluded. Public history begins with the sanitized export.
