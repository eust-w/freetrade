# 方法与数据边界

## 分组因子

| 因子 | 权重 | 指标 |
| --- | ---: | --- |
| 估值 | 16% | 动态 PE、PB、PE / 报告期净利增速 |
| 成长 | 22% | 营收同比、净利同比、三年营收 CAGR |
| 质量 | 17% | ROE、毛利率、经营现金流 / 净利润 |
| 动量 | 25% | 20/60 日收益、均线趋势条件 |
| 资金 | 20% | 主力净流入占比、净流入 / 流通市值 |

权重固定，不是动态学习结果。组内单指标先做 1% / 99% 裁剪，再按候选截面排序。估值因子反向计分。分数是相对排序，不是未来上涨概率。

## 区间

短期锚点为 MA5 与 MA10 的均值，以 ATR14 的不同倍数形成观察、止损与目标区间。长期锚点参考 MA20、MA60 和当前样本价格；过热条件改变区间。该公式表达研究假设，没有证明适用于任一证券或账户。

## 数据

可选真实采集使用东方财富公开接口与 AKShare。库的代码许可不等于上游数据再分发许可；使用者应遵守数据提供方条款、访问限制及适用要求。本仓库提供合成示例，不分发原始行情表。

财报期需显式选择，不会自动保证“最新”。接口返回数据也不保证对历史时点可得。data_as_of 是候选 K 线日期的最小值，不能替代财报发布时间、交易日历和来源级时间戳。

## 暂未实现

回测、基准超额收益、交易成本、换手约束、持仓优化、时点财报数据库、新闻打分、北向资金因子、自动下单与模型训练均不在本版本内。
