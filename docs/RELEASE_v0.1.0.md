# FreeTrade v0.1.0

看得懂的分数，追得溯的数据。

FreeTrade 是规则驱动的 A 股研究原型：公开五因子筛选逻辑、静态面板、显式数据状态，以及 127 份保留日志的脱敏摘要。它不是自动交易系统，不提供收益承诺。

## 本次交付

- 无账号、无 API Key 的标准库离线演示，使用合成数据。
- JSON 快照、数据日期、显式缓存回退、HTML 转义与部署内容一致性检查。
- 框架设计、项目分析、方法边界与逐次运行记录。
- 12 项回归测试通过；依赖审计和密钥扫描通过，首轮 GitHub CI 成功。
- 75 秒中文演示，横版与竖版成片、三种封面、制作脚本和分镜。
