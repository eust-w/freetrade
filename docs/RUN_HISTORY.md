# 运行记录与证据边界

公开记录来自旧部署保留的 127 份日志，时间范围为 2026-06-15 16:39:46 至 2026-09-01 12:01:19（Asia/Shanghai）。它不是完整计划任务清单，也不意味着之后没有运行。

| 状态 | 份数 | 含义 |
| --- | ---: | --- |
| live | 5 | 日志含实时路径的成功结果 |
| fallback | 105 | 日志含降级渲染成功 |
| unknown | 17 | 没有完整成功事件，不强行判定原因 |
| HTTP 200 | 110 | 日志记录页面连通；不证明数据新鲜度 |

## 文件

- [runs.jsonl](runs/runs.jsonl)：每份日志一行，保留开始时间标识、状态、候选数量、HTTP 状态与大小。
- [summary.json](runs/summary.json)：从上述记录计算汇总。
- [导出脚本](../scripts/export_run_history.py)：可审查白名单导出逻辑。

## 脱敏方式

仅提取预定义字段，不直接替换后发布原始文本。移除了本机目录、部署地址、用户名、证券名单、原始堆栈与任意非白名单内容。source_sha256 用于让持有原日志的人比对对应关系，不提供原日志内容的独立可见性证明。

```bash
python scripts/export_run_history.py /path/to/private/logs docs/runs
```

示例统计不能被写成“成功率 86.6%”：渲染成功、HTTP 连通、数据获取成功和研究有效性是不同事件。17 条 unknown 也不能武断归为上游故障。

本次开源版的测试与演示记录单独列在 [VALIDATION.md](VALIDATION.md)，不会混入旧部署统计。
