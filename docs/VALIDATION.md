# 开源版验证

日期：2026-10-24。此文件记录公开版本的本次验证，独立于旧部署历史日志。

## v0.1.1 双语演示增量

- 回归测试：15 passed，新增翻译完整性、字幕边界进位和逐段帧时码测试。
- 四份成片均完成 FFmpeg 全量解码检查，未报告解码错误；逐句双语字幕布局已生成并检查关键画面。
- 中文配音成片约 69.8 秒，英文配音成片约 68.8 秒；每种语言都有 1920×1080 与 1080×1920 输出。
- H.264/AAC，音轨标注 `zho` / `eng`；每种配音附中文、英文、双语 SRT。
- 发布附件有 SHA-256 校验；原中文单语社交帖子保留，未冒充新双语视频。
